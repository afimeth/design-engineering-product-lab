# Architecture

Deterministic trade fixtures feed derived totals and filters. Component state drives journal/review/risk controls. Validated browser storage restores reviewed IDs and risk limits. A native dialog provides modal behavior and focus return. Vite produces relative-path static assets for Pages or Cloudflare.

## Tradeoff

The lab optimizes local reproducibility and an inspectable failure boundary. The architecture is intentionally small enough to explain during an interview.

## Evidence boundaries

Brokerage integration, conversion experimentation and manual assistive-technology review remain extensions.
