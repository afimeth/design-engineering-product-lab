# Design rationale

Clearstep serves a trader reviewing a session, with synthetic examples. The primary job is reflection, followed by setting a journal reminder.

Palette: paper blue #EDF3F8, ink #16354D, action blue #124E78, positive #1B6352, negative #AA3445. Georgia headlines introduce a calm reflective voice; Calibri/Trebuchet system fonts keep controls legible without external font requests. The journal dominates the left column; the risk boundary stays visible on the right, then stacks on mobile.

Rejected direction: a dense trading terminal with flashing prices. It distracts from reviewing decisions. Rejected direction: generic promotional cards; this is a usable product surface. Profit/loss always includes a signed number rather than color alone. Native form controls and dialog preserve familiar browser interactions.

AI assisted implementation and test generation; no claim of hand-authored production employment or independent design review. Browser feedback corrected a filter accessible label. Automated axe, keyboard focus, persistence and viewport checks measure exercised states. Manual screen-reader review and user research remain open.

Asset budget: 85,000 gzip bytes for built JS + CSS. The measured report is generated by `npm run budget`; latency and conversion performance are not claimed.
